# TradeMind AI

An AI-powered trading intelligence platform built with **TypeScript**, **Node.js**, and **Clean Architecture**.

## 🚀 Vision

TradeMind AI is designed to provide traders with intelligent market analysis by combining quantitative indicators, market structure, and AI reasoning into a single modular platform.

This project is being built with scalability, maintainability, and clean software engineering principles from the very beginning.

---

## ✨ Current Features

- Market data retrieval from MEXC
- Modular Data Engine
- Exchange Adapter Pattern
- Analysis Engine
- Statistical Analysis
- REST API
- TypeScript Architecture
